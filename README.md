# 哈工大（深圳）《数字逻辑设计》实验课程

本项目为哈尔滨工业大学（深圳）《数字逻辑设计》（2026秋季）课程的实验工程与代码仓库。实验基于 Xilinx 7 系列 FPGA（Artix-7）硬件平台与 Vivado 集成设计环境，采用 Verilog HDL 语言完成数字逻辑电路建模、行为级仿真验证、底层逻辑综合与板级硬件验证。

## 仓库架构与多 Lab 设计规范

本仓库采用“总纲 + 分实验子目录”的层次化架构设计：
- **根目录 `README.md`（本文档）**：全面概述实验课程背景、软硬件环境、代码规范、Grader 提交规则及全学期实验进度索引。

## 实验软硬件环境与使用规范

### 1. 硬件平台
- **Minisys 实验板**：主芯片型号为 Xilinx Artix-7 `xc7a100tfgg484-1`。板载 24 个拨码开关、24 个绿色 LED、8 位动态数码管、矩阵键盘及丰富扩展外设。
- **EGO1 实验板**：主芯片型号为 Xilinx Artix-7 `xc7a35tcsg324-1`。
- **外设与管脚约束**：物理管脚约束必须严格对照指导书中的《外设接口与芯片引脚对应关系表》，设定正确的 I/O 电平标准（通常为 `LVCMOS33`）。

### 2. 软件与 EDA 工具
- **EDA 工具**：Xilinx Vivado ML Edition（推荐 2020.2 / 2023.2+ 版本）。
- **仿真内核**：Vivado Simulator (XSim)。
- **高级应用**：支持通过校内 Slurm GPU 集群远端无头调用 Vivado 脚本批处理执行综合实现与仿真波形导出（VCD 格式）。

### 3. 实验室电脑与数据安全注意事项
- **还原卡机制**：T2 教学楼所有实验室电脑 C 盘、T2612 与 T2615 实验室 D 盘均配置有重启自动还原卡，**重启后未备份的文件将被彻底清除**。
- **代码管理原则**：所有源码工程必须及时通过 Git 提交推送到远程云端仓库，或妥善保存在移动存储设备中，切勿仅暂存在实验室本地磁盘。

## Verilog 代码设计与编写规范

为了保证电路综合质量，避免产生非预期时序违例和多余硬件开销，所有设计模块需严格遵守以下代码规范：

1. **复位与初始化规范**：
   - 组合逻辑电路严禁添加复位信号；时序逻辑电路必须设置同步或异步复位信号（`rst` / `rst_n`）；
   - 严禁在 RTL 可综合模块中使用 `initial` 语句赋初值，时序逻辑的状态初始化必须在复位有效期间完成。
2. **赋值方式规范**：
   - 组合逻辑电路中的过程块（`always @(*)`）统一使用**阻塞赋值**（`=`）；
   - 时序逻辑电路中的时钟敏感块（`always @(posedge clk)`）统一使用**非阻塞赋值**（`<=`）；
   - 严禁在同一个 `always` 块中混用阻塞赋值与非阻塞赋值。
3. **锁存器（Latch）防范**：
   - 组合逻辑的所有条件分支（`if-else` 或 `case` 语句）必须保持完备，必须包含 `default` 或完整 `else` 分支，杜绝因分支未覆盖而综合出电平敏感的意外锁存器。
4. **模块命名与注释**：
   - 文件名必须与模块名严格保持一致（大小写敏感）；
   - 端口信号必须明确标明数据方向、位宽范围及功能注释。

## 课程作业与实验报告提交规则 (Grader 平台)

实验交付通过 [HITSZ Grader 系统](https://grader.hitsz.edu.cn/courses/718) 统一管理，请务必严格遵守以下提交要求：

### 1. 提交文件组织要求
每次实验仅提交学生自主编写的核心成果，打包为单个 `.zip` 文件提交：
- **设计文件**：`*.v`（Verilog 设计源码，如 `mux.v`）
- **约束文件**：`*.xdc`（物理引脚约束文件，如 `pin.xdc`）
- **实验报告**：`学号_姓名.pdf` 或 `report.pdf`（内容清晰的 PDF 报告）
- **禁止提交整项 Vivado 工程**：自动生成的临时文件（`.runs`, `.cache`, `.sim`, `*.dcp`, `*.bit` 等）禁止上传，提交整个工程将酌情扣分。

### 2. 截止时间与考核政策
- **提交时间**：所有班级截止时间统一，通常在实验后两周内截止（以 Grader 标注截止时间为准）。截止时间前可重复提交，以最终版本为准。
- **迟交惩罚**：
  - 迟交 1 周（$7 \times 24$ 小时）以内：扣除该次实验报告成绩的 **10%**；
  - 迟交 1 周以上：扣除该次实验报告成绩的 **20%**。
- **学术诚信**：
  - 报告内容雷同者，双方均记 **0 分**；
  - 禁止直接大段引用 AI 生成的套话，应切实记录实测现象、精确数值与真实波形。
