# 哈工大（深圳）《数字逻辑设计》实验课程

本项目为哈尔滨工业大学（深圳）计算机科学与技术学院《数字逻辑设计》（2026秋季）课程的实验工程与代码仓库。

本课程依托工业级 EDA 工具 **Xilinx Vivado** 与 **Artix-7 FPGA** 实验平台，采用 **Verilog HDL** 硬件描述语言，涵盖从组合逻辑电路、运算部件、时序逻辑部件到复杂数字系统设计的全套正向设计、行为级仿真、综合布线与硬件验证流程。

## 实验软硬件环境与操作规范

### 1. 硬件平台与外设
- **Minisys 实验板**：主芯片为 Xilinx Artix-7 `xc7a100tfgg484-1`。板载 24 个拨码开关、24 个绿色 LED、8 位动态数码管、矩阵键盘及丰富外设；
- **EGO1 实验板**：主芯片为 Xilinx Artix-7 `xc7a35tcsg324-1`；
- **时钟与复位规范**：
  - 时钟源连接板载 100MHz 晶振（Minisys 为 `Y18` 引脚，EGO1 为 `P17` 引脚）；
  - 复位信号连接板载轻触按键（Minisys 推荐按键 `S1`，引脚 `R1`；EGO1 为 `R17`），按键按下输出高电平 `1`，未按下输出低电平 `0`；
- **引脚配置**：必须严格对照指导书《外设接口与芯片引脚对应关系表》与开发板硬件手册，配置正确的 I/O 电平标准（统一采用 `LVCMOS33`）。

### 2. EDA 软件环境
- **开发工具**：Xilinx Vivado Design Suite（推荐 2020.2 / 2023.2+ 版本）；
- **仿真器**：Vivado Simulator (XSim)；
- **集群与云平台支持**：支持通过校内 Slurm GPU 集群远端无头批处理执行 Vivado 仿真与比特流综合导出（VCD 格式）。

### 3. 实验室电脑使用与数据安全规范
- **还原卡机制**：T2 教学楼所有机房电脑 C 盘、T2612 与 T2615 机房 D 盘均装有还原卡，**电脑重启后未备份的新建文件将被彻底清除**。
- **备份策略**：必须养成随做随将代码提交推送至 Git 云端仓库或 U 盘外部存储的习惯，避免数据丢失。

## Verilog 代码设计与编写规范

所有硬件设计源文件必须严格遵守以下代码规范：

1. **复位与初始化规范**：
   - 组合逻辑电路严禁添加复位信号；时序逻辑电路必须设置复位信号（`clr` / `rst`）；
   - 时序电路使用上升沿触发 `always @(posedge clk or posedge clr)`；
   - 严禁在 RTL 可综合代码中使用 `initial` 语句赋初值，时序逻辑的初始状态必须在复位信号有效时进行赋值。
2. **过程块赋值规范**：
   - 组合逻辑电路（`always @(*)`）统一使用**阻塞赋值**（`=`）；
   - 时序逻辑电路（`always @(posedge clk)`）统一使用**非阻塞赋值**（`<=`）；
   - 严禁在同一 `always` 块中混用阻塞赋值与非阻塞赋值；
   - 遵循“一个 `always` 块只给一个变量赋值”。
3. **分频时钟规范**：
   - 严禁将计数器分频产生的信号直接作为其他模块的工作时钟；
   - 正确做法是以计数器溢出产生的单周期脉冲作为使能信号（Tick/Enable），全系统保持统一时钟域。
4. **避免产生非预期锁存器 (Latch)**：
   - 组合逻辑的过程块中，条件判断（`if-else` 或 `case` 语句）必须保持分支完备，必须包含 `default` 或完整 `else`，避免因逻辑遗漏而综合出电平敏感的意外锁存器。
5. **命名规范**：
   - 模块名与 Verilog 文件名必须严格保持一致（大小写敏感）；
   - 明确标注端口信号的输入输出方向、位宽范围与功能说明。

## 课程作业与实验报告提交规则 (Grader 平台)

实验交付通过 [HITSZ Grader 平台](https://grader.hitsz.edu.cn/courses/718) 统一管理：

### 1. 提交文件要求
每次实验仅提交学生自主编写的核心成果，打包为单个 `.zip` 文件提交：
- **设计文件**：`*.v`（Verilog 设计源码）
- **约束文件**：`*.xdc`（物理引脚约束文件）
- **实验报告**：`学号_姓名.pdf`（清晰排版的 PDF 报告）
- **禁止提交整项 Vivado 工程**：自动生成的临时文件（`.runs`, `.cache`, `.sim`, `*.dcp`, `*.bit` 等）禁止提交，提交整个工程将酌情扣分。

### 2. 截止时间与评分政策
- **提交时间**：所有班级截止时间统一，通常在实验后两周内截止（以 Grader 标注截止时间为准）。截止时间前可重复提交，以最后一次为准。
- **迟交惩罚**：
  - 迟交 1 周（7 × 24 小时）以内：扣除该次实验报告成绩的 **10%**；
  - 迟交 1 周以上：扣除该次实验报告成绩的 **20%**。
- **学术诚信**：
  - 报告内容雷同者，双方均记 **0 分**；
  - 禁止直接大段引用 AI 生成的套话，应切实记录实测现象、精确数值与真实波形；
  - 涉及学生卡拍照的实物图片属于个人隐私，仅用于课程报告核验，严禁上传至公开代码仓库。
