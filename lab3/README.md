# 实验3：计数器与可调流水灯 (Counter & Flowing Lights)

本实验为哈尔滨工业大学（深圳）《数字逻辑设计》课程的第三次实验。实验以**时序电路的核心基础——计数器**为切入点，掌握在 Verilog HDL 中通过计数器产生精准分频使能脉冲的方法；基于计数器实现**时间间隔可调、方向可调、模式可调的 8 位流水灯**控制系统，并在 Minisys 开发板上完成物理引脚约束、行为级仿真验证与硬件上板测试。

---

## 一、实验目的

1. 熟练掌握时序逻辑电路的 Verilog HDL 设计方法与调试技能；
2. 掌握计数器分频控制的核心思想，理解“以使能脉冲（Tick）作为控制信号”的纯同步时钟设计原则（严禁使用分频时钟作为异步时钟）；
3. 掌握带参数 `parameter` 的模块化设计规范，学会利用位拼接符 `{}` 实现循环移位与多模式流水灯控制；
4. 学习时序电路 Testbench 的编写与调试技巧，掌握在仿真工具中将大计数参数调小以便高效观察时序波形的方法；
5. 掌握在 Minisys 开发板上利用板载 100MHz 晶振、轻触按键与拨码开关对系统进行功能演示与检查。

## 二、模块设计与硬件接口 (`flowing_lights.v`)

### 2.1 模块接口定义与参数规范

```verilog
`timescale 1ns / 1ps

module flowing_lights #(
    parameter CNT_500HZ = 24'd199999,   // 100MHz / 500Hz - 1 (0.002s 对应计数上限)
    parameter CNT_10HZ  = 24'd9999999   // 100MHz / 10Hz  - 1 (0.1s 对应计数上限)
) (
    input  wire       clk,        // 100MHz 板载晶振主时钟输入
    input  wire       rst,        // 异步复位信号（轻触按键 S1，高有效）
    input  wire       freq_ctrl,  // 频率控制端（拨码开关 SW0: 0->500Hz, 1->10Hz）
    input  wire       dir_ctrl,   // 方向控制端（拨码开关 SW1: 0->循环右移, 1->循环左移）
    input  wire       model_set,  // 模式控制端（拨码开关 SW7: 0->单灯流水, 1->双灯流水）
    output reg  [7:0] leds        // 8 位流水灯输出（驱动绿色发光二极管 GLD7~GLD0）
);
```

### 2.2 核心架构与设计规范

1. **分频使能脉冲机制（严格遵循同步设计原则）**：
   - 动态计数上限选择：`wire [23:0] current_cnt = (freq_ctrl == 1'b0) ? CNT_500HZ : CNT_10HZ;`
   - 计数器满清零并生成使能：`wire cnt_end = (cnt == current_cnt); wire en = cnt_end;`
   - 该使能信号 `en` 每个移位周期只拉高一个时钟周期，作为移位寄存器的同步使能端，**整个电路保持单一 100MHz 时钟域，杜绝门控时钟或异步多时钟导致的冒险竞争**。
2. **流水灯移位与状态自愈控制**：
   - 统计当前点亮的灯数：`wire [3:0] led_counts = leds[0] + leds[1] + ... + leds[7];`
   - **复位响应**：按下 S1（`rst = 1`）时，流水灯复位只亮 `leds = 8'h01`（对应 LED0）；
   - **单灯模式（`model_set == 0`）**：
     - 若灯数异常（如刚从双灯切入），自愈复位为 `8'h01`；
     - 正常状态下根据 `dir_ctrl` 进行拼接循环移位：右移 `{leds[0], leds[7:1]}`，左移 `{leds[6:0], leds[7]}`；
   - **双灯模式（`model_set == 1`）**：
     - 若灯数异常（如刚从复位或单灯切入），自愈为 `8'h03`；
     - 正常状态下根据 `dir_ctrl` 循环移位：右移 `{leds[1:0], leds[7:2]}`，左移 `{leds[5:0], leds[7:6]}`。

## 四、仿真激励与时序规范 (`testbench.v`)

### 4.1 参数调小与全流程测试

在仿真测试平台 `tb_flowing_lights` 中，通过参数传递将计数值缩减为：
- `CNT_500HZ = 24'd6`（覆盖 `cnt` 从 **0 到 6** 循环）；
- `CNT_10HZ  = 24'd11`（覆盖 `cnt` 从 **0 到 11** 循环）；

仿真按实验要求的标准流程依次注入激励：
1. **阶段 1：复位阶段（0 ~ 30 ns）**：`rst = 1`，输出强制保持 `leds = 8'h01`，`cnt = 0`；30ns 释放复位；
2. **阶段 2：频率切换阶段（30 ~ 450 ns）**：
   - 30 ~ 190ns（500Hz 档，`freq_ctrl = 0`）：`cnt` 在 `0~6` 之间循环，`leds` 依次单灯右移；
   - 190 ~ 450ns（10Hz 档，`freq_ctrl = 1`）：`cnt` 扩展在 `0~11` 之间循环，移位间隔明显延长；
3. **阶段 3：模式切换阶段（450 ~ 850 ns）**：
   - 将 `model_set` 切换为 1（双灯模式），流水灯自愈过渡为 `8'h03`，随后连续双灯循环右移（`8'h03 -> 8'hc0 -> 8'h30`）。

## 五、课后计算题推导：20Hz 流水灯计数器最大值

**题目要求**：时钟频率 100MHz，给出流水灯 20Hz 频率对应的计数器变量 `cnt` 应达到的最大值的计算过程，`cnt` 从 0 开始。

### 严密推导过程

1. **时钟周期计算**：
   $$f_{clk} = 100\,\text{MHz} = 10^8\,\text{Hz} \implies T_{clk} = \frac{1}{f_{clk}} = 10\,\text{ns}$$
2. **流水灯流动间隔周期**：
   $$f_{flow} = 20\,\text{Hz} \implies T_{flow} = \frac{1}{f_{flow}} = 0.05\,\text{s} = 50\,\text{ms} = 50 \times 10^6\,\text{ns}$$
3. **分频总时钟周期数（模数 $N$）**：
   $$N = \frac{T_{flow}}{T_{clk}} = \frac{0.05\,\text{s}}{10 \times 10^{-9}\,\text{s}} = 5,000,000$$
4. **计数器最大值（$\text{CNT\_MAX}$）**：
   - `cnt` 从 0 开始计数（$0, 1, 2, \dots, N-1$），因此最大计数值为：
     $$\text{CNT\_MAX} = N - 1 = 5,000,000 - 1 = 4,999,999$$
5. **所需位宽**：
   $$\lceil \log_2(5,000,000) \rceil = 23\,\text{位} \quad (2^{22} < 5,000,000 \le 2^{23})$$
   工程中一般分配 24 位宽 `reg [23:0] cnt`。
