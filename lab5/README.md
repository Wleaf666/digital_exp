# 实验5：状态机与 UART 串口发送 (FSM & UART Transmitter)

本实验为哈尔滨工业大学（深圳）《数字逻辑设计》课程的第五次实验。实验以**经典有限状态机（FSM）与异步串行通信协议（UART）**为核心，掌握使用 Verilog HDL **三段式状态机**建模规范实现 UART 发送器；完成以 9600 波特率（8N1 帧格式）循环向电脑端串口调试助手发送个人学号字符串 **`hitsz2025311308`** 的系统设计。

本项目同时提供了针对 **Minisys 开发板 (XC7A100T)** 与 **EGO1 开发板 (XC7A35T)** 两种硬件平台的完整工程源码。

## 一、实验目的与核心规范要求

### 1. 实验目标
1. 掌握状态机电路的分析与设计方法，熟练绘制状态转换图；
2. 掌握使用 Verilog HDL 语言进行状态机**三段式描述**的规范与工程实践；
3. 理解 UART 异步串行通信协议的数据帧格式（起始位、数据位、停止位、波特率）；
4. 在 FPGA 上实现 UART 发送控制系统，稳定将字符串发送至 PC 端串口软件并格式化接收。

### 2. 核心技术指标
- **发送内容**：循环发送固定字符串 **`hitsz2025311308`**（共 15 个 ASCII 字符）；
- **字符间发送间隔**：字符串内部相邻字符之间（如 `'h'` 与 `'i'`）间隔 **<= 0.01 秒 (10ms)**；
- **字符串间发送间隔**：整串字符串发送完毕后，等待间隔 **>= 0.2 秒 (200ms)** 再重复发送；
- **波特率参数**：9600 bps，每位持续时间约 104.16 微秒（在 100MHz 时钟下对应 10,416 个时钟周期）；
- **帧格式（8N1）**：
  - 1 位低电平起始位（Start Bit）；
  - 8 位数据位（Data Bits，**低位 LSB 在前，高位 MSB 在后**）；
  - 1 位高电平停止位（Stop Bit）；
  - 空闲状态（IDLE）保持高电平。
- **串口显示要求**：电脑端串口调试软件（如 SuperCom）勾选“加时间戳”，**每一行完整显示一次 `hitsz2025311308`**，不能出现跨行或分行。

## 二、双平台工程架构与模块划分

系统采用自顶向下的分层设计，划分为发送器核心（`uart_send`）与顶层调度器（`top`）：

```
                          top 顶层调度模块
     +--------------------------------------------------------------+
     |                                                              |
clk ─┼─> 字符序列发生器 (hitsz2025311308)                            |
rst ─┼─> 定时状态控制 (字符间隔 2.0ms，整串间隔 250ms)                  |
     |         |                    |                               |
     |         v valid (单拍脉冲)    v data[7:0] (当前字符 ASCII)    |
     |    +-----------------------------+                           |
     |    |   uart_send (三段式状态机)   |                           |
     |    |   9600 波特率数据帧序列化    |                           |
     |    +--------------┬--------------+                           |
     |                   |                                          |
     +-------------------|------------------------------------------+
                         v
                      uart_tx (物理发送引脚)
```

### 1. 核心模块与文件清单
- **`uart_send.v`**：UART 发送核心模块，严格遵守实验指定接口，采用三段式状态机实现，定义 IDLE、START、DATA、STOP 四个状态；
- **`top.v`**：顶层集成模块，生成 `hitsz2025311308` 字符序列，控制字符间 2.0ms（<= 10ms）及串间 250ms（>= 200ms）间隔并产生 `valid` 触发脉冲；
- **`uart_send_tb.v`**：官方仿真验证激励平台，逐位校验 5 组测试用例并测量波特率精度；
- **`pin.xdc`**：物理引脚约束文件（分别针对 Minisys 与 EGO1 平台）。

## 三、三段式状态机设计与状态转移原理

### 1. 状态定义
```verilog
localparam IDLE  = 2'b00; // 空闲状态：输出高电平，等待 valid 脉冲
localparam START = 2'b01; // 起始位状态：输出低电平，维持 10416 周期
localparam DATA  = 2'b10; // 数据位状态：依次发送 8 位数据 (LSB 先发)，每位 10416 周期
localparam STOP  = 2'b11; // 停止位状态：输出高电平，维持 10416 周期
```

### 2. 状态转移图 (State Transition Diagram)

```
        复位 (rst=1) / 初始上电
                 |
                 v
           +-----------+  valid=0
           |           |<---------+
           |   IDLE    |          |
           |           |----------+
           +-----------+
                 | valid=1 (锁存待发数据 data_reg <= data, 输出起始位低电平)
                 v
           +-----------+  cnt < 10415
           |           |<---------+
           |   START   |          | (每位维持 10416 拍)
           |           |----------+
           +-----------+
                 | cnt == 10415 (起始位结束，输出第0位数据 data_reg[0])
                 v
           +-----------+  cnt < 10415 (位内累加)
           |           |<---------+
           |   DATA    |          |
           |           |----------+ (cnt==10415 且 bit_idx<7: 切到下一位)
           +-----------+
                 | cnt == 10415 且 bit_idx == 7 (8位数据发送完毕，输出停止位高电平)
                 v
           +-----------+  cnt < 10415
           |           |<---------+
           |   STOP    |          |
           |           |----------+
           +-----------+
                 | cnt == 10415 (停止位结束，数据帧完成)
                 v
             (回到 IDLE)
```

### 3. 三段式代码划分规范
- **第 1 段（同步时序逻辑）**：描述现态向次态的迁移（`state <= next_state`）；
- **第 2 段（组合逻辑）**：根据现态和输入条件（`valid`、`cnt` 满、`bit_idx` 满）判断次态（`next_state`）；
- **第 3 段（同步时序逻辑）**：描述状态对应的输出与内部寄存器行为（`dout` 电平更新、`cnt` 波特率分频计数、`bit_idx` 索引推进、`data_reg` 数据锁存）。

## 五、仿真验证与 Tcl Console 判定方法

### 1. 运行仿真流程
1. 打开工程后，点击左侧导航栏 **Run Simulation -> Run Behavioral Simulation**；
2. 在波形界面打开后，默认运行时间（1000ns）不足以跑完 UART 的完整测试（9600 波特率下一个位就需要 104,160ns）；
3. 在上方仿真控制栏点击 **Run All**（或在下方 Tcl 控制台输入 `run all`）；
4. 观察仿真运行完成并自动停止在 `$finish`。

### 2. Tcl Console 日志判定标准
仿真结束后，点击 Vivado 界面下方的 **Tcl Console** 标签页，查看测试日志：
- 正确实现的标志：末尾必须输出：
  ```
  Test case :a5 start
  Test case a5 success
  Test case :3c start
  Test case 3c success
  Test case :ff start
  Test case ff success
  Test case :00 start
  Test case 00 success
  Test case :5a start
  Test case 5a success
  All tests passed successfully!
  Uart baud rate = 9600, freq divider = 10415
  ```
- 若显示 `All tests passed successfully!` 且 `0 errors detected`，即证明波特率计数精度、移位顺序、数据锁存与空闲极性全部通过严格校验。

## 六、完成实验报告所需获取的图片与数据全指南

编写实验五报告时，共需获取 **三组核心图片与数据**，详细操作指引如下：

---

### 第一部分：串口软件接收到的数据截图（报告第一题）

#### 1. 获取目标
- 获取电脑端串口调试软件（SuperCom 或其他串口助手）接收到学号字符串的**高清电脑屏幕截图**（严禁用手机拍照屏幕！无需放学生卡）。

#### 2. 操作与配置要点
1. **硬件连接与端口识别**：
   - 将开发板通过 USB 数据线连接电脑，打开开发板电源开关；
   - 打开 Windows“设备管理器” -> “端口 (COM 和 LPT)”，查看识别到的端口号（例如 `COM5`）；
2. **SuperCom 参数配置**：
   - 波特率选择：**`9600`**；
   - 数据位：**`8`**；校验位：**`None`**；停止位：**`1`**；
   - **必选勾选**：勾选界面上的 **“加时间戳”** 复选框；
   - 接收格式选择文本（STR）模式；
3. **烧录与观察**：
   - 在 Vivado 中将生成的比特流文件（`top.bit`）烧录入板；
   - 观察 SuperCom 接收窗口：每一行均以时间戳开头，且每行完整显示一次 **`hitsz2025311308`**；
   - 连续接收 5 行以上，时间戳间隔显示为约 0.25 秒（250ms）；
4. **截图规范**：
   - 使用 `Win + Shift + S` 截取 SuperCom 窗口清晰图片；
   - 截图中必须清晰看清：端口配置参数（9600）、连续多行带有时间戳的文本 `hitsz2025311308`，无分行、无乱码。

---

### 第二部分：状态转移图（报告第二题）

#### 1. 获取目标
- 绘制与 `uart_send.v` 代码严格对应的**电子版状态转移图**（使用 draw.io、Visio、PowerPoint 或 Markdown 导出高清图）。

#### 2. 状态图必须包含的要素（评分硬性规范）
1. **四个闭环状态圆圈**：
   - `IDLE`（编码 2'b00，输出 dout = 1）
   - `START`（编码 2'b01，输出 dout = 0）
   - `DATA`（编码 2'b10，输出 dout = data_reg[bit_idx]）
   - `STOP`（编码 2'b11，输出 dout = 1）
2. **状态跳转条件与转移箭头**：
   - 复位箭头：指向 `IDLE` 初始状态；
   - `IDLE` 状态：
     - 若 `valid == 1`：转移到 `START`；
     - 若 `valid == 0`：自循环保持在 `IDLE`；
   - `START` 状态：
     - 若 `cnt == 10415`（波特率满）：转移到 `DATA`；
     - 若 `cnt < 10415`：自循环保持在 `START`；
   - `DATA` 状态：
     - 若 `cnt == 10415 && bit_idx == 7`（8位发完）：转移到 `STOP`；
     - 若 `cnt == 10415 && bit_idx < 7`：自循环保持在 `DATA` 并推进 `bit_idx`；
     - 若 `cnt < 10415`：自循环保持在 `DATA`；
   - `STOP` 状态：
     - 若 `cnt == 10415`：转移回 `IDLE`（完成闭环）；
     - 若 `cnt < 10415`：自循环保持在 `STOP`。
3. **输出标明**：
   - 每个状态需清晰标注输出信号 `dout` 的取值。

---

### 第三部分：uart_send 模块仿真波形截图与波形分析（报告第三题）

#### 1. 获取目标
- **截图 A**：Vivado 下方 Tcl Console 显示 `All tests passed successfully!` 的日志截图；
- **截图 B**：波形窗口中覆盖一个完整数据帧（起始位 + 8位数据位 + 停止位）的时序截图。

#### 2. 波形窗口信号添加与设置
在仿真波形窗口中，添加以下信号：
1. `clk`（系统时钟）
2. `rst`（复位信号）
3. `valid`（输入有效脉冲）
4. `data[7:0]`（输入待发送数据，Radix 设为 **Hexadecimal**）
5. `u_uart_send.state[1:0]`（现态，Radix 设为 **Binary** 或在波形中映射状态名）
6. `u_uart_send.next_state[1:0]`（次态）
7. `u_uart_send.bit_idx[2:0]`（数据位索引，Radix 设为 **Unsigned Decimal**）
8. `u_uart_send.cnt[13:0]`（波特率分频计数器，Radix 设为 **Unsigned Decimal**）
9. `dout`（输出发送信号线）

#### 3. 截取完整数据帧（以 Test 1: 8'hA5 为例）
- **时间视窗调节**：
  - 缩放到第一个测试用例 `8'hA5`（二进制 `01010101`）发送区间（大约从 120ns 到 1,041,800ns）；
  - 完整呈现一个数据帧的 10 个位：
    - 起始位：`dout = 0`，状态为 START（维持 104,160ns = 10,416 周期）；
    - 数据位 0：`dout = 1`（A5 的第 0 位），状态为 DATA；
    - 数据位 1：`dout = 0`（A5 的第 1 位）；
    - 数据位 2：`dout = 1`；
    - 数据位 3：`dout = 0`；
    - 数据位 4：`dout = 0`；
    - 数据位 5：`dout = 1`；
    - 数据位 6：`dout = 0`；
    - 数据位 7：`dout = 1`；
    - 停止位：`dout = 1`，状态为 STOP；
    - 空闲态：`dout = 1`，状态回到 IDLE。
- **波形分析文字撰写要点**：
  - 明确写出现态与次态在时钟沿上的跳转关系；
  - 明确写出起始位为低电平 `0`、停止位为高电平 `1`；
  - 指出数据位从最低位（bit 0 = 1）到最高位（bit 7 = 1）依次串行输出，波形完全符合 `8'hA5` 编码；
  - 指出每一位的时间跨度均为 10,416 个时钟周期（约 104.16 微秒），严格满足 9600 波特率标准。
