## 一、实验内容与考核核心要求

### 1. 功能目标
1. **模式 2.1（固定学号显示）**：
   - 拨码开关 `SW0 = 1`（上拨）；
   - 8 位七段数码管（DK7 ~ DK0）稳定显示个人学号后 8 位。
   - **当前学生学号**：`2025311308` -> 后 8 位为 **`25311308`**（DK7 显 2，DK6 显 5，...，DK0 显 8）。
2. **模式 2.2（多功能指定内容动态显示）**：
   - 拨码开关 `SW0 = 0`（下拨）；
   - 8 位数码管从左至右分配如下：
     - **DK7 - DK6**：显示学号后两位 **`08`**；
     - **DK5 - DK4**：按键 S3 **无消抖计数**（00 ~ 99 两位十进制，持续按住只计一次）；
     - **DK3 - DK2**：按键 S3 **消抖后计数**（00 ~ 99 两位十进制，持续按住只计一次）；
     - **DK1 - DK0**：间隔为 0.1s 的 **0 到 20 十进制计数器**，复位后自动启动，按键 S2 控制暂停与继续（S2 要求消抖）。
3. **全局异步复位**：
   - 轻触按键 S1（`rst`，按下为 1），复位所有计数器与状态机。

### 2. 报告结构与硬性指标
- **第一部分**：数码管控制器仿真波形截图与波形分析；
  - 8 位数码管轮询过程（每个数码管周期缩短为 10 个时钟周期，学号设置为十六进制显示）；
  - 模拟带抖动的按键输入波形，体现 **2 次消抖计数**。
- **第二部分**：两级寄存器级联的边沿检测仿真波形截图与分析；
- **第三部分**：边沿检测 RTL 截图（**必须使用红框准确标记出两级寄存器级联的位置**）。

## 二、工程建立与代码文件组织

在实验室 Vivado 中新建工程 `seg_ctrl`，器件选择 `xc7a100tfgg484-1`（Minisys）。

将本目录下 `seg_ctrl_project/` 中的核心源码添加进工程：
- **设计文件（Design Sources）**：
  - `seg_ctrl_top.v`：顶层多功能控制模块；
  - `led_ctrl_unit.v`：数码管动态扫描驱动核心模块；
  - `edge_detect.v`：两级寄存器级联边沿检测模块；
  - `btn_debounce.v`：硬件计时按键消抖模块。
- **仿真文件（Simulation Sources）**：
  - `testbench.v`：综合激励平台（已内置快速仿真参数和模拟按键抖动序列）。
- **约束文件（Constraints）**：
  - `seg_ctrl.xdc`：Minisys 物理管脚与电平约束。

## 三、仿真波形调测与截图指引（报告第一、二部分）

在 Vivado 中点击左侧 **Run Simulation -> Run Behavioral Simulation**。

### 1. 截图一：数码管轮询仿真波形（报告 1.1 节）
- **时间范围**：截取 `0 ~ 850ns` 区间；
- **信号添加**：
  - `clk`、`rst`、`sw0`；
  - `display[31:0]`（在波形中选中该信号 -> 右键 -> **Radix -> Hexadecimal**，确认数值为 `25311308`，严禁展开显示！）；
  - `led_en[7:0]`（Radix 设为 Binary 或 Hex，显示位选轮流拉低）；
  - `led_cx[7:0]`（Radix 设为 Hexadecimal，显示对应字符段选码）。
- **关键测量与说明点**：
  - 指出复位释放后，`led_en` 依次从 `8'b1111_1110`（DK0 选通）变到 `8'b0111_1111`（DK7 选通）；
  - 用光标测量：每个数码管位选使能时间恰好为 10 个时钟周期（100ns），8 个数码管轮流点亮一圈总计 800ns；
  - 对照学号字符 `2, 5, 3, 1, 1, 3, 0, 8` 指出对应输出的段选码（如 8 对应 `8'h01`，0 对应 `8'h03`，1 对应 `8'h9F` 等）。

### 2. 截图二：按键消抖对比与 2 次计数波形（报告 1.2 节）
- **时间范围**：截取 `900ns ~ 2000ns` 区间；
- **信号添加**：
  - `btn_s3`（输入的模拟带毛刺按键波形）；
  - `u_dut.u_deb_s3.btn_clean`（消抖后的稳定方波）；
  - `raw_s3_cnt[7:0]`（无消抖计数值，右键设为 **Unsigned Decimal**）；
  - `deb_s3_cnt[7:0]`（消抖后计数值，右键设为 **Unsigned Decimal**）。
- **关键说明点**：
  - 指出由于输入 `btn_s3` 存在快速前沿和后沿抖动（毛刺宽度 < 50ns），无消抖通路直接检测跳变，导致 `raw_s3_cnt` 发生多次误触发异常累加；
  - 消抖模块利用连续稳定计时机制过滤了短时毛刺，输出 `btn_clean` 为规整的高电平，使 `deb_s3_cnt` 在两次完整按键过程中严格只累加了 2 次（计数值依次为 1 和 2）。

### 3. 截图三：两级寄存器级联的边沿检测波形（报告第二部分）
- **时间范围**：在按键上升沿附近放大（放大到约 50ns ~ 100ns 视窗）；
- **信号添加**：
  - `clk`；
  - `u_dut.u_edge_s3_raw.signal`（输入信号）；
  - `u_dut.u_edge_s3_raw.sig_r0`（第一级采样触发器输出）；
  - `u_dut.u_edge_s3_raw.sig_r1`（第二级延迟触发器输出）；
  - `u_dut.u_edge_s3_raw.pos_edge`（边沿脉冲输出）。
- **时序分析说明**：
  - 第 1 拍：输入信号跳变，在时钟上升沿被 `sig_r0` 捕获，`sig_r0` 变高，此时 `sig_r1` 仍为低；
  - 逻辑输出：`pos_edge = sig_r0 & ~sig_r1` 立即变为高电平 1；
  - 第 2 拍：下一个时钟上升沿，`sig_r1` 锁存 `sig_r0` 的高电平变高；
  - 脉冲截断：`pos_edge` 变回 0。无论外部输入按键持续多久，输出严格产生宽度为 1 个时钟周期的单脉冲。

## 四、RTL 级联结构查看与红框标记指引（报告第三部分）

本部分是实验报告评分的**必检重点**，必须提供清晰的 RTL 原理图并按要求使用红框标记：

1. **打开 RTL 视图**：
   - 在 Vivado 左侧导航栏 **RTL Analysis** 下，点击 **Open Elaborated Design -> Schematic**；
2. **定位边沿检测模块**：
   - 在弹出的顶层原理图中，找到实例化的子模块 `u_edge_s3_raw` 或 `u_edge_s2`（显示为独立方框）；
   - 双击或右键选择 **Push into block**（进入子模块内部）；
3. **查看两级级联结构**：
   - 模块内部会清晰显示两个串联的寄存器原语：`sig_r0_reg` 和 `sig_r1_reg`；
   - 输入 `signal` 接到 `sig_r0_reg` 的 D 端，其 Q 端连接到 `sig_r1_reg` 的 D 端，两者的时钟端共同连接主时钟 `clk`；
4. **截图与红框标注**：
   - 截取该局部原理图；
   - 使用画图或截图工具，**用红色粗线矩形框**将 `sig_r0_reg` 和 `sig_r1_reg` 这两个串联的触发器框出，并在图中注明“两级寄存器级联（打两拍）”。

## 五、开发板硬件上板验证与验收指引

### 1. 综合实现与烧录
1. 点击左侧 **Generate Bitstream**，等待 Vivado 完成综合、实现与比特流生成；
2. 用 Type-C 线连接 Minisys 开发板，拨开电源开关（电源指示灯亮）；
3. 点击 **Open Hardware Manager -> Auto Connect**，识别到 `xc7a100t` 芯片；
4. 点击 **Program Device**，选择 `seg_ctrl_top.bit` 烧录入板。

### 2. 现场验收操作流程
1. **测试模式 2.1（学号显示）**：
   - 将拨码开关 `SW0` 向上拨（`sw0 = 1`）；
   - 观察 8 位数码管：稳定显示 `25311308`，无抖动、无残影。
2. **测试模式 2.2（多功能显示）**：
   - 将拨码开关 `SW0` 向下拨（`sw0 = 0`）；
   - **检查 DK7-DK6**：稳定显示学号后两位 `08`；
   - **检查 DK1-DK0（0.1s 计数器）**：数码管自动从 `00` 开始以 0.1s 步长累加至 `20`，再回滚至 `00`；点按一次按键 S2，计数暂停；再按一次 S2，计数继续；
   - **检查 DK5-DK4（无消抖）vs DK3-DK2（消抖）**：
     - 轻按按键 S3，观察 DK3-DK2（消抖端）每次严格加 1；
     - 快速连击或轻按 S3 时，对比观察 DK5-DK4（无消抖端）因机械抖动出现一次按键跳变 2 或 3 的现象。
3. **测试复位（按键 S1）**：
   - 任意时刻按一下轻触按键 S1，数码管所有计数器复位清零。
