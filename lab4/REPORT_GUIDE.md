## 一、实验内容与考核核心要求

### 1. 功能目标
1. **模式 2.1（固定学号显示）**：
   - 拨码开关 SW0 = 1（上拨）；
   - 8 位七段数码管（从左往右 DK7 ~ DK0）稳定显示个人学号后 8 位。
   - **当前学生学号**：2025311308 -> 后 8 位为 **25311308**（DK7 显 2，DK6 显 5，...，DK0 显 8）。
2. **模式 2.2（多功能指定内容动态显示）**：
   - 拨码开关 SW0 = 0（下拨）；
   - 8 位数码管从左至右分配如下：
     - **DK7 - DK6**：显示学号后两位 **08**；
     - **DK5 - DK4**：按键 S3 **无消抖计数**（00 ~ 99 两位十进制，持续按住只计一次）；
     - **DK3 - DK2**：按键 S3 **消抖后计数**（00 ~ 99 两位十进制，持续按住只计一次）；
     - **DK1 - DK0**：间隔为 0.1s 的 **0 到 20 十进制计数器**，复位后自动启动，按键 S2 控制暂停与继续（S2 要求消抖）。
3. **全局异步复位**：
   - 轻触按键 S1（rst，按下为 1），复位所有计数器与状态机。

### 2. 报告结构与硬性指标
- **第一部分**：数码管控制器仿真波形截图与波形分析；
  - 8 位数码管轮询过程（每个数码管周期缩短为 10 个时钟周期，学号设置为十六进制显示）；
  - 模拟带抖动的按键输入波形，体现 **2 次消抖计数**。
- **第二部分**：两级寄存器级联的边沿检测仿真波形截图与分析；
- **第三部分**：边沿检测 RTL 截图（**必须使用红框准确标记出两级寄存器级联的位置**）。

## 二、EGO1 硬件特性与管脚对照表

EGO1 开发板与 Minisys 的数码管驱动逻辑存在本质差异，请重点注意：
- **EGO1 数码管为共阴极结构**：位选使能信号 `led_en` 与段选信号 `led_cx` 均为**高电平有效（高电平点亮）**；
- **两组分立段选总线**：EGO1 将左右两侧数码管的段选引脚分开（右侧 4 位为 `led_cx`，左侧 4 位为 `led_cx1`）。

### EGO1 物理管脚约束对照表

| 信号名称 | 端口方向 | 位宽 | 对应 FPGA 引脚 | EGO1 外设标识 | 功能与电平规范 |
| :--- | :---: | :---: | :--- | :--- | :--- |
| `clk` | 输入 | 1 | `P17` | 板载 100MHz 晶振 | 系统主时钟输入（周期 10ns） |
| `rst` | 输入 | 1 | `R17` | 轻触按键 `S1` (PB1) | 异步复位（按下为高电平 1） |
| `sw0` | 输入 | 1 | `R1` | 拨码开关 `SW0` | 模式选择（0: 模式2.2多功能, 1: 模式2.1学号） |
| `btn_s2` | 输入 | 1 | `R15` | 轻触按键 `S2` (PB2) | 0~20 计数器暂停/继续控制按键 |
| `btn_s3` | 输入 | 1 | `V1` | 轻触按键 `S3` (PB3) | 按键计数对比测试按键 |
| `led_en[7]` | 输出 | 1 | `G2` | 数码管位选 DK7 | 最左侧数码管（高电平有效） |

| `led_en[4]` | 输出 | 1 | `H1` | 数码管位选 DK4 | 数码管 DK4 |
| `led_en[3]` | 输出 | 1 | `G1` | 数码管位选 DK3 | 数码管 DK3 |

## 三、工程建立与源码模块结构

在实验室电脑 Vivado 中新建工程 `seg_ctrl`，器件型号选择 **`xc7a35tcsg324-1`**。

工程目录 `seg_ctrl_project/` 包含以下文件：
- **`top.v`**：顶层集成模块；
- **`led_ctrl_unit.v`**：数码管 8 位动态扫描与字符段码译码核心模块；
- **`edge_detect.v`**：方式二两级寄存器级联（打两拍）边沿检测模块；
- **`debounce.v`**：硬件计数器消抖滤波模块；
- **`testbench.v`**：仿真测试激励平台；
- **`pin.xdc`**：EGO1 物理引脚约束文件。

## 四、仿真波形调测与截图指引（报告第一、二部分）

在 Vivado 中点击左侧 **Run Simulation -> Run Behavioral Simulation**。

### 1. 截图一：数码管轮询仿真波形（报告 1.1 节）
- **时间范围**：截取 `0 ~ 850ns` 区间；
- **信号添加**：
  - `clk`、`rst`、`sw0`；
  - `display_data[31:0]`（在波形中选中该信号 -> 右键 -> **Radix -> Hexadecimal**，确认数值为 `25311308`，严禁展开显示！）；
  - `led_en[7:0]`（Radix 设为 Binary，显示位选独热码依次移动：`10000000 -> 01000000 -> ... -> 00000001`）；
  - `led_cx[7:0]` 与 `led_cx1[7:0]`（Radix 设为 Hexadecimal，显示对应字符的共阴极段码）。
- **关键测量与说明点**：
  - 指出复位释放后，位选使能 `led_en` 依次轮询 8 个数码管；
  - 测量时间差：每个数码管位选有效时间恰好为 10 个时钟周期（100ns），8 个数码管轮流点亮一圈总耗时 800ns；
  - 列举学号字符 `2, 5, 3, 1, 1, 3, 0, 8` 对应的 EGO1 高电平段码（例如字符 2 对应 `8'hDA`，字符 5 对应 `8'hB6`，字符 0 对应 `8'hFC` 等）。

### 2. 截图二：按键消抖对比与 2 次计数波形（报告 1.2 节）
- **时间范围**：截取 `900ns ~ 2000ns` 区间；
- **信号添加**：
  - `btn_s3`（输入的模拟带毛刺按键波形）；
  - `u_dut.u_debounce_s3.btn_out`（消抖后的稳定信号）；
  - `cnt_raw[7:0]`（未消抖计数值，右键设为 **Unsigned Decimal**）；
  - `cnt_deb[7:0]`（消抖后计数值，右键设为 **Unsigned Decimal**）。
- **关键说明点**：
  - 指出输入 `btn_s3` 在按下和释放时包含宽度小于 50ns 的多次机械弹跳毛刺；
  - 未消抖端由于直接对跳变采样，导致 `cnt_raw` 发生多次错误自增；
  - 消抖模块由于要求电平必须稳定持续超过设定阈值才更新，成功滤除了毛刺，使 `cnt_deb` 在两次按键过程中准确且严格地只计数了 2 次（计数值依次为 1 和 2）。

### 3. 截图三：两级寄存器级联的边沿检测波形（报告第二部分）
- **时间范围**：在按键上升沿跳变处放大（约 50ns ~ 100ns 局部视窗）；
- **信号添加**：
  - `clk`；
  - `u_dut.u_edge_s3_raw.signal`（输入信号）；
  - `u_dut.u_edge_s3_raw.sig_r0`（第一级采样触发器输出）；
  - `u_dut.u_edge_s3_raw.sig_r1`（第二级延迟触发器输出）；
  - `u_dut.u_edge_s3_raw.pos_edge`（边沿单脉冲输出）。
- **时序分析说明**：
  - 第 1 个时钟上升沿：`sig_r0` 采样到输入高电平变 1，此时 `sig_r1` 仍为 0；
  - 组合逻辑判断：`pos_edge = sig_r0 & ~sig_r1` 变为高电平 1；
  - 第 2 个时钟上升沿：`sig_r1` 锁存 `sig_r0` 的电平变为 1；
  - 脉冲截断：`pos_edge` 变回 0。无论外部输入高电平持续多久，输出严格产生宽度为 1 个时钟周期的单脉冲，同时起到了同步和消除亚稳态的作用。

## 五、RTL 级联结构查看与红框标记指引（报告第三部分）

本项是实验报告的核心得分点，必须提供 RTL 原理图并严格按要求标记红框：

1. **进入 RTL 原理图**：
   - 在 Vivado 左侧导航栏 **RTL Analysis** 下，点击 **Open Elaborated Design -> Schematic**；
2. **进入边沿检测子模块**：
   - 在展开的原理图中，找到实例化的 `u_edge_s3_raw`（或 `u_edge_s3_deb`）；
   - 双击方框（或右键选择 **Push into block**）进入模块内部视图；
3. **定位两级级联寄存器**：
   - 内部会清晰呈现两个串联的触发器单元：`sig_r0_reg` 和 `sig_r1_reg`；
   - 外部输入 `signal` 连接到 `sig_r0_reg` 的 D 端，其 Q 端连接到 `sig_r1_reg` 的 D 端，时钟端公共连接 `clk`；
4. **截图与红框标注**：
   - 截取该电路图；
   - 使用截图工具**用红色实线矩形框**将 `sig_r0_reg` 和 `sig_r1_reg` 两个触发器圈选出来，并在图下文字说明该结构即为方式二的两级寄存器级联同步器。

## 六、EGO1 开发板硬件上板验证与验收指引

### 1. 比特流生成与烧录
1. 点击左侧 **Generate Bitstream**，完成综合、实现与比特流文件生成；
2. 用 USB 数据线将 EGO1 开发板连接至电脑，拨开电源开关（电源 LED 亮起）；
3. 点击 **Open Hardware Manager -> Auto Connect**，识别到 `xc7a35t` 芯片；
4. 点击 **Program Device**，选择生成的比特流文件烧录入板。

### 2. 现场功能演示步骤
1. **模式 2.1 演示（学号后 8 位）**：
   - 将拨码开关 `SW0` 向上拨（SW0 = 1）；
   - 观察 8 位数码管：从左往右清晰稳定显示 **25311308**，无重影、无闪烁。
2. **模式 2.2 演示（多功能集成显示）**：
   - 将拨码开关 `SW0` 向下拨（SW0 = 0）；
   - **观察 DK7-DK6**：显示学号后两位 **08**；
   - **观察 DK1-DK0（0.1s 计数器）**：数码管自动从 `00` 开始每 0.1s 递增至 `20`，到 20 后自动归零循环；点按一次按键 S2（R15），计数暂停；再按一次 S2，计数继续；
   - **观察 DK5-DK4（无消抖）vs DK3-DK2（消抖）**：
     - 轻按按键 S3（V1），DK3-DK2 每次严格自增 1；
     - 快速连击或抖动按压 S3 时，观察 DK5-DK4（无消抖端）出现因机械抖动导致一次按键递增 2 或 3 的现象，形成鲜明对比。
3. **复位测试**：
   - 任意时刻按一下轻触按键 S1（R17），所有计数器瞬间清零。
