# 实验4：数码管控制器 (Segment Display Controller)

本实验为哈尔滨工业大学（深圳）《数字逻辑设计》课程的第四次实验（目标硬件平台：**EGO1 开发板，FPGA 主芯片 XC7A35TCSG324-1**）。实验以 **8 位七段数码管动态扫描显示**为核心，掌握共阴极数码管时分复用轮询驱动机制；结合硬件按键输入，掌握基于**两级寄存器级联（打两拍）的边沿检测技术**与**计时按键消抖逻辑**；实现固定学号显示与多功能集成显示（包含学号后两位、未消抖按键计数、消抖按键计数、0.1s 模 21 启停定时器）的数码管控制器系统。

> 提示：本实验包含多模块仿真、带抖动波形调测与 RTL 红框标注等丰富步骤，详细的操作指引与报告撰写说明可直接查阅：[实验报告操作指南 (REPORT_GUIDE.md)](./REPORT_GUIDE.md)。

---

## 一、实验目的

1. 掌握 8 位七段数码管动态扫描（时分复用）的基本原理与驱动时序设计；
2. 掌握使用 Verilog HDL 构建带参数 `parameter` 的分频计数器与动态轮询控制器；
3. 掌握硬件输入信号的“两级寄存器级联”同步边沿检测技术，理解亚稳态抑制与单脉冲截取机制；
4. 掌握机械按键的硬件消抖算法，对比消抖与非消抖电路的实际抗干扰特性；
5. 掌握多数据源在顶层的多路复用与调度，并在 EGO1 开发板上完成功能验收。

## 二、系统设计规范与模块划分

系统采用模块化分层架构设计，各模块职责明确、接口规范：

```
                               top (顶层系统模块)
          +-------------------------------------------------------------+
          |                                                             |
sw0 ----->|                                                             |
btn_s2 -->| debounce -> edge_detect -> 启停控制 -> 0.1s 模21计数器        |
btn_s3 -->|   +- 未消抖通路: edge_detect --------------> 00~99 计数器   |
          |   +- 消抖通路  : debounce -> edge_detect -> 00~99 计数器    |
          |                                                             |
          |   显示数据多路选择: 学号后8位 "25311308" vs 多功能指定内容  |
          |                           |                                 |
          |                           v [31:0] display_data             |
          |                  led_ctrl_unit (数码管扫描驱动)              |
          +-------------------------------------------------------------+
                                      |            |
                                      v            v
                               led_en[7:0]    led_cx[7:0] & led_cx1[7:0]
                              (8位数码管位选)       (左右两组段选引脚)
```

### 核心模块清单 (`seg_ctrl_project/`)

1. **`top.v`（顶层集成控制模块）**：
   - **模式 2.1（`sw0 = 1`）**：8 位数码管固定显示学号后 8 位 `25311308`；
   - **模式 2.2（`sw0 = 0`）**：
     - DK7-DK6：学号后两位 `08`；
     - DK5-DK4：S3 按键未消抖计数（00~99 两位十进制，持续按住只计一次）；
     - DK3-DK2：S3 按键消抖后计数（00~99 两位十进制，持续按住只计一次）；
     - DK1-DK0：0.1s 间隔的 0~20 循环计数器，S2 按键消抖控制启停；
   - **异步复位（`rst`，S1 按键）**：按下复位所有计数器。
2. **`led_ctrl_unit.v`（数码管扫描核心驱动）**：
   - 接收 32 位显示向量 `display[31:0]`（8 个十六进制字符）；
   - 采用分频计数器产生 1ms 轮询节拍（仿真时参数调小为 10 个时钟周期）；
   - 输出 8 位位选使能 `led_en[7:0]`（高电平有效）与两组段选码 `led_cx[7:0]`、`led_cx1[7:0]`（高电平点亮）。
3. **`edge_detect.v`（两级寄存器级联边沿检测）**：
   - 外部异步信号经第一级触发器 `sig_r0` 与第二级触发器 `sig_r1` 级联同步；
   - 组合逻辑输出 `pos_edge = sig_r0 & ~sig_r1`，提取标准 1 拍高电平脉冲，彻底抑制亚稳态。
4. **`debounce.v`（硬件按键消抖滤波）**：
   - 采用 10ms 连续稳定计时滤波算法，过滤按键机械弹跳过程中的高低毛刺；
   - 仅当输入电平连续稳定保持超过 10ms 时更新输出 `btn_out`。
5. **`testbench.v`（仿真测试平台）**：
   - 涵盖数码管轮询、带抖动模拟按键对比及两级寄存器边沿检测全流程仿真。
6. **`pin.xdc`（EGO1 物理约束文件）**：
   - 对应 EGO1 开发板的物理管脚约束。

## 四、仿真激励与时序规范 (`testbench.v`)

测试平台 `testbench.v` 按照实验报告要求顺序完成验证：
1. **数码管轮询验证（0 ~ 900ns）**：
   - 模式设为 `sw0 = 1`；
   - 传参设置 `SCAN_CNT_MAX = 10`，每个数码管使能 10 个时钟周期；
   - 8 个数码管在 800ns 内完整轮询一周，波形直观对应学号 `32'h25311308`。
2. **按键消抖对比验证（900 ~ 2000ns）**：
   - 模式切换为 `sw0 = 0`；
   - 注入两次带前后沿多次毛刺（宽度 < 50ns）的模拟按键抖动序列；
   - 观察未消抖计数器 `cnt_raw` 发生多次异常自增，而消抖计数器 `cnt_deb` 严格只计数 2 次。
3. **两级级联边沿检测时序验证**：
   - 局部展开观测两级触发器 `sig_r0` 与 `sig_r1` 的前后节拍延迟，以及 `pos_edge` 单拍输出。
