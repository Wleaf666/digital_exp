# 实验2：触发器与寄存器文件 (DFF & Register File)

本实验为哈尔滨工业大学（深圳）《数字逻辑设计》课程的第二次实验。实验从最基础的时序逻辑存储单元——**D 触发器**出发，深入理解时钟边沿触发、异步清零与同步使能的时序行为；随后将触发器扩展为 8 位位宽，构建由 8 个 8 位寄存器组成的**通用寄存器文件（Register File / 寄存器堆）**，实现具有同步写操作与异步读操作的核心数据暂存部件，并完成 Vivado 逻辑综合实现与硬件验证。

---

## 一、实验目的

1. 掌握使用 Verilog HDL 语言描述时序逻辑电路的基本规范（时钟上升沿敏感、非阻塞赋值 `<=`、异步复位逻辑）；
2. 掌握带异步复位（`clr`）与同步使能（`en`）的 D 触发器设计与仿真；
3. 理解 CPU 核心部件——寄存器堆（Register File）的硬件架构与工作机制，掌握二维寄存器数组的 Verilog 声明与寻址访问方法；
4. 掌握时序逻辑电路的 Testbench 编写规范，深入理解时钟生成、边沿对齐、同步写入与异步读取的时序特征；
5. 掌握在 Minisys 开发板上利用板载 100MHz 晶振、轻触按键、拨码开关及 LED 指示灯进行时序电路硬件验证的方法。

## 二、任务一：D 触发器设计与验证 (`dff`)

### 2.1 模块接口与设计源码

设计具有**异步复位、同步使能**的 1 位 D 触发器（见工程 `diff_project`）：

```verilog
`timescale 1ns / 1ps

module dff (
    input      clk,  // 100MHz 板载时钟
    input      clr,  // 异步复位信号，高电平有效
    input      en ,  // 同步使能信号，高电平有效
    input      d  ,  // 1 位数据输入
    output reg q     // 1 位数据输出
);

always @ (posedge clk or posedge clr) begin
    if (clr) begin
        q <= 1'b0;  // 异步清零：不受时钟控制，直接复位
    end else if (en) begin
        q <= d;     // 同步使能写入：仅在时钟上升沿且使能开启时采样 d
    end
end

endmodule
```

### 2.2 引脚分配约束 (`diff.xdc`)

在 Minisys 开发板（Xilinx Artix-7 `xc7a100tfgg484-1`）上的管脚映射：

| 信号名称 | 端口位宽 | 对应 FPGA 引脚 | 开发板器件标识 | 操作说明 |
| :--- | :---: | :---: | :--- | :--- |
| `clk` | 1 | `Y18` | 100MHz 板载晶振 | 系统主时钟 |
| `clr` | 1 | `R1` | 轻触按键 `S1` | 异步清零按键（按下为 1，松开为 0，只需点按一次） |
| `en` | 1 | `U6` | 拨码开关 `SW7` | 同步使能开关（向上拨为 1，向下为 0） |
| `d` | 1 | `W4` | 拨码开关 `SW0` | 数据输入开关（向上拨为 1，向下为 0） |
| `q` | 1 | `A21` | 绿色 LED `GLD0` | 输出数据显示（高电平点亮，低电平熄灭） |

## 三、任务二：8位×8深度 寄存器文件设计与验证 (`reg8file`)

### 3.1 模块设计源码

构建由 8 个 8 位寄存器组成的通用寄存器堆，包含同步写端口与异步读端口（见工程 `reg8file_project`）：

```verilog
`timescale 1ns / 1ps

module reg8file (
    input  wire clk,         // 100MHz 时钟信号
    input  wire clr,         // 异步复位信号，高电平有效，将 8 个寄存器全部清零
    input  wire en,          // 同步写使能信号，高电平有效
    input  wire [7:0] d,     // 8 位写入数据输入
    input  wire [2:0] wsel,  // 3 位写寄存器编号选择 (0~7)
    input  wire [2:0] rsel,  // 3 位读寄存器编号选择 (0~7)
    output reg  [7:0] q      // 8 位读出数据输出，驱动板载 LED 显示
);

reg [7:0] regfile[7:0];      // 内部 8 个 8 位寄存器阵列
integer i;

// 1. 同步写逻辑（带异步复位）
always @ (posedge clk or posedge clr) begin
    if (clr) begin
        for (i = 0; i < 8; i = i + 1) begin
            regfile[i] <= 8'h00; // 硬件完全展开并行清零
        end
    end else if (en) begin
        regfile[wsel] <= d;      // 同步写选通寄存器
    end
end
    
// 2. 异步读逻辑（纯组合逻辑，零等待直接输出）
always @ (*) begin
    q = regfile[rsel];
end

endmodule
```

### 3.2 实测物理管脚分配表 (`reg8.xdc`)

在 Minisys 开发板上的实际配置映射：

| 信号名称 | 端口位宽 | 对应 FPGA 引脚 | 开发板器件标识 | 实验功能用途 |
| :--- | :---: | :---: | :--- | :--- |
| `clk` | 1 | `Y18` | 100MHz 晶振 | 主时钟源 |
| `clr` | 1 | `R1` | 轻触按键 `S1` | 异步全局清零按键 |
| `en` | 1 | `Y9` | 拨码开关 `SW23` | 写使能控制端（上拨开启写，下拨关闭） |
| `wsel[2]` | 1 | `W9` | 拨码开关 `SW22` | 写地址最高位（Bit 2） |
| `wsel[1]` | 1 | `Y7` | 拨码开关 `SW21` | 写地址次高位（Bit 1） |
| `wsel[0]` | 1 | `Y8` | 拨码开关 `SW20` | 写地址最低位（Bit 0） |
| `rsel[2]` | 1 | `AA8` | 拨码开关 `SW18` | 读地址最高位（Bit 2） |

| `rsel[0]` | 1 | `V9` | 拨码开关 `SW16` | 读地址最低位（Bit 0） |
| `d[7~0]` | 8 | `U6, W5, W6, U5, T5, T4, R4, W4` | 拨码开关 `SW7 ~ SW0` | 8 位数据输入（SW7为高位，SW0为低位） |
| `q[7~0]` | 8 | `F21, G22, G21, D21, E21, D22, E22, A21` | 绿色 LED `GLD7 ~ GLD0` | 8 位数据显示（GLD7为高位，GLD0为低位） |

## 四、仿真激励与时序波形分析规范 (`testbench.v`)

测试平台按如下六个关键阶段完成全流程覆盖验证：

```
+---------------------------------------------------------------------------------------+
|  阶段1: 初始复位   |  阶段2: 写入两个寄存器   |  阶段3: 关闭使能  |  阶段4: 异步读取测试   |  阶段5: 异步清零  |  阶段6: 清零后读取  |
|  0 ~ 15 ns        |  15 ~ 35 ns            |  35 ~ 45 ns      |  45 ~ 75 ns           |  75 ~ 95 ns       |  95 ~ 125 ns       |
|  clr=1, q=8'h00   |  写Reg[2]=A5, Reg[5]=3C |  en=0, d=FF保持  |  读Reg[2]=A5, 读[5]=3C |  非边沿clr=1立即归零 |  读Reg[2]/[5]均为00  |
+---------------------------------------------------------------------------------------+
```

1. **初始复位阶段（0 ~ 15 ns）**：`clr = 1`，全部寄存器初始化为 0，输出 `q = 8'h00`；
2. **同步写入阶段（15 ~ 35 ns）**：
   - 20ns 上升沿：向 `wsel = 3'd2` 写入数据 `d = 8'hA5`；
   - 30ns 上升沿：向 `wsel = 3'd5` 写入数据 `d = 8'h3C`；
3. **保持测试阶段（35 ~ 45 ns）**：拉低 `en = 0`，修改 `d = 8'hFF`，验证寄存器内容不被误改写；
4. **异步读取阶段（45 ~ 75 ns）**：
   - `rsel = 3'd2`：输出 `q` 瞬间变为 `8'hA5`，无需等待时钟边沿；
   - `rsel = 3'd5`：输出 `q` 瞬间变为 `8'h3C`；
   - `rsel = 3'd0`：未写入寄存器保持读出 `8'h00`；
5. **异步清零阶段（75 ~ 95 ns）**：保持 `rsel = 3'd2`，在时钟低电平区间（82ns）拉高 `clr = 1`，观察到 `q` 瞬间由 `8'hA5` 跃变归零为 `8'h00`，验证了纯异步硬件复位特性；
6. **清零后校验阶段（95 ~ 125 ns）**：释放复位后，切换读地址到 5 号寄存器，输出依然为 `8'h00`，证明 8 个寄存器全部被清零。

## 五、硬件上板实测验证步骤

上板实物测试步骤如下：

1. **初始置位**：将所有拨码开关全部拨到下方（输入低电平 `0`）；
2. **向 2 号寄存器写入数值 3 并读取**：
   - 拨动写地址开关 SW22~SW20 设定 `wsel = 3'd2`（`010`）；
   - 拨动数据输入开关 SW7~SW0 设定输入数值为 `3`（`00000011`）；
   - 将 SW23 (`en`) 向上拨为 1，在时钟上升沿数据 3 写入 2 号寄存器；随后拨回 0 关闭写使能；
   - 将读地址开关 SW18~SW16 拨为 `010`（读取 2 号寄存器），观察到板载绿色 LED 呈现 `GLD1`、`GLD0` 点亮（即二进制 `8'b00000011`，数值 3）；
3. **向 5 号寄存器写入数值 5 并读取**：
   - 拨动写地址开关 SW22~SW20 设定 `wsel = 3'd5`（`101`）；
   - 拨动数据输入开关 SW7~SW0 设定输入数值为 `5`（`00000101`）；
   - 将 SW23 (`en`) 向上拨为 1 写入数据；随后拨回 0 关闭写使能；
   - 将读地址开关 SW18~SW16 切换拨为 `101`（读取 5 号寄存器），观察到板载绿色 LED 呈现 `GLD2`、`GLD0` 点亮（即二进制 `8'b00000101`，数值 5）；
4. **异步清零后再次读取验证**：
   - 在上述 LED 点亮状态下，按一下板载轻触按键 S1，所有绿色 LED 瞬间全部熄灭；
   - 保持读地址指向 2 或 5，再次观察 LED，依然保持全灭（即二进制 `8'b00000000`，数值 0）。
