# 实验2：触发器与寄存器文件 (DFF & Register File)

本实验为哈尔滨工业大学（深圳）《数字逻辑设计》课程的第二次实验。实验从最基础的时序逻辑存储单元——**D 触发器**出发，深入理解时钟边沿触发、异步清零与同步使能的时序行为；随后将触发器扩展为 8 位位宽，构建由 8 个 8 位寄存器组成的**通用寄存器文件（Register File / 寄存器堆）**，实现具有同步写操作与异步读操作的核心数据暂存部件，并完成 Testbench 仿真与 FPGA 板级硬件验证。

---

## 一、实验目的

1. 掌握使用 Verilog HDL 语言描述时序逻辑电路的基本规范（时钟上升沿敏感、非阻塞赋值 `<=`、异步复位逻辑）；
2. 掌握带异步复位（`clr`）与同步使能（`en`）的 D 触发器设计与仿真；
3. 理解 CPU 核心部件——寄存器堆（Register File）的硬件架构与工作机制，掌握二维寄存器数组的 Verilog 声明与寻址访问方法；
4. 掌握时序逻辑电路的 Testbench 编写规范，深入理解时钟生成、边沿对齐、同步写入与异步读取的时序特征；
5. 掌握在 Minisys 开发板上利用板载 100MHz 晶振、轻触按键、拨码开关及 LED 指示灯进行时序电路硬件验证的方法。

## 二、任务一：D 触发器设计与验证 (`dff`)

### 2.1 模块接口与设计规范

设计具有**异步复位、同步使能**的 1 位 D 触发器，模块接口定义如下：

```verilog
module dff (
    input  wire clk,  // 100MHz 板载时钟信号输入
    input  wire clr,  // 异步复位信号，高电平有效
    input  wire en,   // 同步使能信号，高电平有效
    input  wire d,    // 1 位数据输入
    output reg  q     // 1 位数据输出
);
```

#### 逻辑行为设计 (`dff.v`)

```verilog
always @(posedge clk or posedge clr) begin
    if (clr) begin
        q <= 1'b0;      // 异步复位：不受时钟控制，直接清零
    end
    else if (en) begin
        q <= d;         // 同步写入：仅在时钟上升沿且使能开启时锁存 d
    end
    // else 自动保持当前状态
end
```

### 2.2 引脚分配约束 (`dff_pin.xdc`)

在 Minisys 开发板（Xilinx Artix-7 `xc7a100tfgg484-1`）上的管脚映射：

| 信号名称 | 端口类型 | 位宽 | FPGA 管脚 | 板载外设标识 | 操作说明 |
| :--- | :---: | :---: | :---: | :--- | :--- |
| `clk` | 输入 | 1 | `Y18` | 100MHz 板载晶振 | 系统主时钟 |
| `clr` | 输入 | 1 | `R1` | 轻触按键 `S1` | 异步清零按键（按下为 1，松开为 0，只需点按一次） |
| `en` | 输入 | 1 | `U6` | 拨码开关 `SW7` | 同步使能开关（向上拨为 1，向下为 0） |
| `d` | 输入 | 1 | `W4` | 拨码开关 `SW0` | 数据输入开关（向上拨为 1，向下为 0） |
| `q` | 输出 | 1 | `A21` | 绿色 LED `GLD0` | 输出数据显示（高电平点亮，低电平熄灭） |

### 2.3 硬件上板实测验证步骤

1. **写入测试**：将拨码开关 SW7 (`en`) 向上拨为 1（使能开启）。上下拨动 SW0 (`d`) 改变输入数据，观察板载绿色 LED GLD0 (`q`) 同步随之点亮或熄灭；
2. **保持测试**：将拨码开关 SW7 (`en`) 向下拨为 0（使能关闭）。此时无论如何拨动 SW0 改变输入，GLD0 的状态均保持恒定不变，验证数据被锁存；
3. **清零测试**：在 GLD0 点亮的情况下，轻按一次板载轻触按键 S1 (`clr`)，GLD0 立即熄灭，验证异步清零功能的有效性。

## 三、任务二：8位×8深度 寄存器文件设计与验证 (`reg8file`)

### 3.1 模块原理与接口定义

将 D 触发器位宽扩展为 8 位，深度扩展至 8 个（地址编号 0 ~ 7），构成 8 个 8 位的通用寄存器堆。包含一个同步写端口和一个异步读端口：

```verilog
module reg8file (
    input  wire       clk,   // 100MHz 时钟信号
    input  wire       clr,   // 异步复位信号，高电平有效，将 8 个寄存器全部清零
    input  wire       en,    // 同步写使能信号，高电平有效
    input  wire [7:0] d,     // 8 位写入数据输入
    input  wire [2:0] wsel,  // 3 位写寄存器编号选择 (0~7)
    input  wire [2:0] rsel,  // 3 位读寄存器编号选择 (0~7)
    output reg  [7:0] q      // 8 位读出数据输出，驱动板载 LED 显示
);
```

#### 关键实现技术与代码架构 (`reg8file.v`)

1. **内部寄存器数组定义**：
   ```verilog
   reg [7:0] regfile [7:0]; // 8 个 8 位宽寄存器
   ```
2. **同步写操作（带异步复位）**：
   ```verilog
   integer i;
   always @(posedge clk or posedge clr) begin
       if (clr) begin
           for (i = 0; i < 8; i = i + 1) begin
               regfile[i] <= 8'h00; // 异步清零全部寄存器
           end
       end
       else if (en) begin
           regfile[wsel] <= d;      // 同步写选通的寄存器
       end
   end
   ```
3. **异步读操作（组合逻辑零延迟输出）**：
   ```verilog
   always @(*) begin
       q = regfile[rsel];           // 纯异步读取，地址变输出立即可变
   end
   ```

### 3.2 引脚分配约束 (`reg8file_pin.xdc`)

在 Minisys 开发板上的管脚映射如下：

| 信号名称 | 端口位宽 | 对应 FPGA 引脚 | 开发板器件标识 | 实验功能用途 |
| :--- | :---: | :---: | :--- | :--- |
| `clk` | 1 | `Y18` | 100MHz 板载晶振 | 时钟源信号 |
| `clr` | 1 | `R1` | 轻触按键 `S1` | 异步全局清零按键 |
| `en` | 1 | `Y9` | 拨码开关 `SW23` | 写使能控制端（上拨写，下拨关闭） |
| `wsel[2:0]` | 3 | `Y8, AB8, AA8` | 拨码开关 `SW20 ~ SW18` | 写地址编号（SW20为高位，SW18为低位） |
| `rsel[2:0]` | 3 | `V8, V9, AB6` | 拨码开关 `SW17 ~ SW15` | 读地址编号（SW17为高位，SW15为低位） |
| `d[7:0]` | 8 | `U6, W5, W6, U5, T5, T4, R4, W4` | 拨码开关 `SW7 ~ SW0` | 8 位数据输入（SW7为高位，SW0为低位） |
| `q[7:0]` | 8 | `F21, G22, G21, D21, E21, D22, E22, A21` | 绿色 LED `GLD7 ~ GLD0` | 8 位数据显示（GLD7为高位，GLD0为低位） |

## 四、仿真激励与时序波形分析规范 (`testbench.v`)

测试平台按如下六个关键阶段完成全流程覆盖验证：

```
+---------------------------------------------------------------------------------------+
|  阶段1: 初始复位   |  阶段2: 写入两个寄存器   |  阶段3: 关闭使能  |  阶段4: 异步读取测试   |  阶段5: 异步清零  |  阶段6: 清零后读取  |
|  0 ~ 15 ns        |  15 ~ 35 ns            |  35 ~ 45 ns      |  45 ~ 75 ns           |  75 ~ 95 ns       |  95 ~ 125 ns       |
|  clr=1, q=8'h00   |  写Reg[2]=A5, Reg[5]=3C |  en=0, d=FF保持  |  读Reg[2]=A5, 读[5]=3C |  非边沿clr=1立即归零 |  读Reg[2]/[5]均为00  |
+---------------------------------------------------------------------------------------+
```

1. **初始复位阶段（0 ~ 15 ns）**：`clr = 1`，全部寄存器初始化为 0，输出 `q = 8'h00`；
2. **同步写入阶段（15 ~ 35 ns）**：
   - 20ns 上升沿：向 `wsel = 3'd2` 写入数据 `d = 8'hA5`（二进制 `10100101`）；
   - 30ns 上升沿：向 `wsel = 3'd5` 写入数据 `d = 8'h3C`（二进制 `00111100`）；
3. **保持测试阶段（35 ~ 45 ns）**：拉低 `en = 0`，修改 `d = 8'hFF`，验证寄存器内容不被误改写；
4. **异步读取阶段（45 ~ 75 ns）**：
   - `rsel = 3'd2`：输出 `q` 瞬间变为 `8'hA5`，无需等待时钟边沿；
   - `rsel = 3'd5`：输出 `q` 瞬间变为 `8'h3C`；
   - `rsel = 3'd0`：未写入寄存器保持读出 `8'h00`；
5. **异步清零阶段（75 ~ 95 ns）**：保持 `rsel = 3'd2`，在时钟低电平区间（82ns）拉高 `clr = 1`，观察到 `q` 瞬间由 `8'hA5` 跃变归零为 `8'h00`，验证了纯异步硬件复位特性；
6. **清零后校验阶段（95 ~ 125 ns）**：释放复位后，切换读地址到 5 号寄存器，输出依然为 `8'h00`，证明 8 个寄存器全部被清零。

## 五、硬件上板推荐验证步骤 (对应报告三张图)

根据课程报告要求，测试需体现 **2 次读取和清零后再读取一次的结果（共 3 张照片）**：

1. **初始置位**：将所有拨码开关全部拨到下方（输入低电平 `0`）；
2. **向寄存器 2 写入非零数据并读取（第 1 张图）**：
   - 拨动 SW20~SW18 选定写地址为 `010`（2 号寄存器）；
   - 拨动 SW7~SW0 设置待写入数据为 `8'hA5`（`10100101`）；
   - 将 SW23 (`en`) 向上拨为 1，数据写入寄存器 2；随后将 SW23 拨回 0 关闭写使能；
   - 将读地址开关 SW17~SW15 拨为 `010`（读 2 号寄存器），观察到 GLD7~GLD0 呈现 `亮-灭-亮-灭-灭-亮-灭-亮`（即 `8'hA5`），**与学生卡同框拍下第 1 张照片**；
3. **向寄存器 5 写入不同数据并读取（第 2 张图）**：
   - 拨动 SW20~SW18 选定写地址为 `101`（5 号寄存器）；
   - 拨动 SW7~SW0 设置待写入数据为 `8'h3C`（`00111100`）；
   - 将 SW23 (`en`) 向上拨为 1，写入数据；随后拨回 0 关闭使能；
   - 将读地址开关 SW17~SW15 切换为 `101`（读 5 号寄存器），观察到 GLD7~GLD0 呈现 `灭-灭-亮-亮-亮-亮-灭-灭`（即 `8'h3C`），**与学生卡同框拍下第 2 张照片**；
4. **异步清零后再次读取验证（第 3 张图）**：
   - 在上述 LED 点亮状态下，按一下轻触按键 S1，所有绿色 LED 瞬间全部熄灭；
   - 保持读地址指向 2 或 5，再次观察 LED，依然全灭（`8'h00`），**与学生卡同框拍下第 3 张照片**。
